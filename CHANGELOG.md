# Changelog

## 0.1 (first preview)

First public preview.

- Open `.csv` and `.tsv` files as a table from the editor title bar or the Explorer context menu. The text editor stays the default.
- Editing a cell rewrites only that cell's text. Quotes are added only when needed.
- Spreadsheet-style selection: Shift+click, Ctrl+click, drag, Shift+arrow keys, row and column headers, Ctrl+A and the corner box.
- Copy and paste with Google Sheets and Excel, cell by cell. Pasting one value fills the selection, and pasting past the end grows the table.
- Header modes (first row, first column, none) with alternating stripes, shared by all files.
- Resize columns and rows by dragging, with double-click to fit or reset.
- Zoom with Ctrl+mouse wheel and the zoom buttons. Sizes and zoom are remembered per file.
- Find with Ctrl+F across the whole file.
- Insert and delete rows and columns from the right-click menu.
- English and Korean user interface.
